# P2 Prompts

## Prompt 1

Start code/79_q2.pl with a predicate that splits a list into non-empty left and right parts at every position.

## Prompt 2

Add a predicate that generates every expression tree over a list of numbers in order, with its value, using + - * / and allowing division only when exact and the divisor is non-zero.

## Prompt 3

Add a predicate that converts a tree to the canonical string using the precedence and parenthesis rules in the PDF. Test it on (4+2)*3, 8/(4*2), 1-(2-3), 1+(2+3).

## Prompt 4

Add generate_equation/2, all_equations/2 (sorted with sort/2) and count_equations/2. Run the three examples from the PDF.

## Prompt 5

Write tests/test_q2.pl with the PDF examples plus edge cases: [], [5], [0,0], [1,0], [6,0,3], then run it.
